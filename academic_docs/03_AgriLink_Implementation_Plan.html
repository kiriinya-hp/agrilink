We will configure standard PWA (Progressive Web App) manifest, service worker, and app icons. Detailed Component Specifications

1. Email Verification System

  • Database (schema.prisma):
  • Add isEmailVerified Boolean @default(false)
  • Add verificationCode String?
  • Backend API (api.js):
  • POST /api/auth/send-verification: Generates a secure 6-digit OTP code, saves to user record, sends email.
  • POST /api/auth/verify-email: Validates entered OTP code; marks isEmailVerified = true.
  • Frontend UI:
  • Status banner when unverified: "✉️ Your email is unverified. Click to verify your account."
  • Interactive 6-digit verification code modal with resend timer.

    • 2. Farmer Produce Image URL & Interactive Image Selector

  • Farmer Portal (App.jsx):
  • Image input with:
    • 1. Custom URL paste box with instant real-time thumbnail preview. 2. Curated gallery of verified Kenyan fresh produce photos (Tomatoes, Red Onions, Hass Avocados, Irish Potatoes, White Maize, Cabbage, Spinach, Carrots, Capsicum) that farmers can select with 1 click.
  • Image validation to ensure images render cleanly on the marketplace cards.

    • 3. Real-Time Available Transporters Count for Buyers

  • Backend API:
  • GET /api/transporters/count: Returns count of active, verified logistics drivers registered in the system (e.g., in the corridor or nationwide).
  • Marketplace & Checkout UI:
  • Badge on each produce card: "🚚 4 Transporters Active"
  • Checkout Drawer: Prominent green logistics assurance indicator:
    • > "🚚 4 Verified Transporters available in this corridor ready for dispatch upon escrow confirmation."

    4. Multi-Channel Disbursement Notification (Email, SMS & WhatsApp)

  • Notification Engine (notificationService.js):
  • Triggered atomically when delivery is confirmed via OTP and funds are disbursed:
  • Email Receipt: Formatted HTML invoice with transaction reference, crop details, kilogram volume, breakdown (Farmer payout, freight, platform fee).
  • SMS Dispatch Message: Concise text message confirming settlement sent to buyer and farmer's phones.
  • WhatsApp Direct Link: https://wa.me/?text=... allowing 1-click sharing of the disbursement receipt directly to WhatsApp.
  • Live in-app Notification Drawer (bell icon in header) so users can inspect real-time SMS & email messages dispatched by the system.

    • 5. Professional UI Overhaul & Deliverables

  • Interactive Settlement Receipt / Invoice Modal:
  • Professional invoice view for completed orders with official AgriLink stamp, breakdown, download/print buttons.
  • Visual Order Milestone Tracker:
  • Step-by-step progress bar (Escrow Locked $\rightarrow$ Cargo Dispatched $\rightarrow$ In Transit $\rightarrow$ Delivered & Settled).
  • Market Price Intelligence Widget:
  • Live benchmark index ticker (prevailing farmgate vs retail prices) for agricultural commodities.

    • 6. Google Play Store & Android Mobile Application Package

  • PWA Configuration (manifest.json):
  • Standalone display mode, theme colors (#16a34a), high-resolution icons (192x192, 512x512).
  • Service worker caching (sw.js) for rapid loading on Android devices.
  • Google Play Store Setup Guide (PLAYSTORE_GUIDE.md):
  • Complete step-by-step instructions to convert the AgriLink PWA into an Android App Bundle (.aab / .apk) ready for the Google Play Store using Google Bubblewrap or Capacitor.

    • 7. Academic PDF Generator Script

  • Node.js script (scripts/generate-academic-docs.js) that renders:
    • 1. project_proposal_chapter_1.md 2. system_modeling_and_design.md 3. implementation_plan.md into clean, beautifully styled printable HTML/PDF documents with formal university coversheets and page numbers.
